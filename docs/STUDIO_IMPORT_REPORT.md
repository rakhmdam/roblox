в исходниках продолжается через Git; ранее Studio сообщал о приостановке live
collaboration в стране. Причина зависания Publish As не установлена.

Установщик вывел `SLIME_IMPORT_OK` с SHA256 выше. Отдельная проверка подтвердила
universe/place, 1749 деталей, включённые Bootstrap и все три новые audio ID.
Старые объекты удалены из ServerStorage после сверки; резервная копия до замены
остаётся локально в `places/backups/BeforeImport-20261030.rbxl` (не коммитится).

При первом переносе File → Import Roblox Model автоматически сдвинул геометрию:

персонажа под островом. Установщик теперь восстанавливает исходную систему
координат по CFrame Garden до переноса объектов. Повторный импорт подтвердил
`SLIME_FLOOR_VERIFIED 0, 1, 0`; персонаж устойчиво стоит и перемещается по острову.

Устаревший Lighting.Technology недоступен скрипту установщика (RobloxScript);
современный LightingStyle и остальные свойства применились. Пакет теперь
пропускает этот устаревший параметр; полный .rbxlx по-прежнему задаёт его при импорте.
