# Сборка foundation-0.0.1

Первая техническая заготовка, не играбельный срез и не принятый этап 0.

## Workflow

Выбран сборщик XML-места на Python 3.10+, без внешних библиотек и плагинов.
Запустить из корня: `python tools/build.py`.
Открыть `places/SlimeSalvage-Test.rbxlx` через File → Open from File в Roblox Studio.
Берег, причал и макеты станций должны быть видны до Play. При Play появляется
предупреждение тестовой сборки. Нет экономики, сохранений, покупок и внешних asset ID.

`assets/shore.json` — источник сцены; `src/` — источник скриптов.
`places/SlimeSalvage-Test.rbxlx` — воспроизводимый результат сборки, коммитится вместе
с исходниками. Сборщик пишет только этот файл. Художественные правки в Studio сначала
сохранить отдельным файлом, затем перенести координаты/размеры/цвета в JSON. Не сохранять
единственную копию ручных правок поверх генерируемого результата: следующая сборка
их заменит. Сложные модели потребуют отдельного версионируемого источника и расширения
сборщика; текущий workflow предназначен только для блочной сцены.

Формат места: https://create.roblox.com/docs/projects/place-files

## Проверка

`python -m unittest discover -s tests -v`

Автоматически проверяются воспроизводимость, внедрение актуальных скриптов,
наличие редактируемого берега и отключённые платёжные/сохраняющие системы.
Это не замена запуску в Studio. Studio на текущем компьютере не найден:
импорт, Play, телефон и несколько клиентов остаются непроверенными.

До следующего этапа: открыть место в Studio, проверить Output, спавн и геометрию;
затем реализовать персональные узлы, серверную добычу с интервалом, рюкзак,
переработку, Ростка, обучение и покупку toolTier2. Критерии — QA-01/02/04/05/06.
