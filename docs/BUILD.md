# Сборка beta-implementation-0.1.0-dev

Реализация беты; технический прогон Studio выполнен, полная приёмка впереди.

## Workflow

Выбран сборщик XML-места на Python 3.10+, без внешних библиотек и плагинов.
Запустить из корня: `python tools/build.py`.
Открыть `places/SlimeSalvage-Test.rbxlx` через File → Open from File в Roblox Studio.
Три острова и восемь баз должны быть видны до Play. При Play загружается
профиль из Test DataStore, затем меню. В неподключённом к Roblox локальном файле
загрузка может завершиться ошибкой: это не повод включать подмену пустым профилем.
Подготовка приватного experience — [RELEASE.md](RELEASE.md). Покупки за Robux отключены.

`tools/world_art.py` — источник статической сцены; `src/` — источник скриптов.
`places/SlimeSalvage-Test.rbxlx` — воспроизводимый результат сборки, коммитится вместе
с исходниками. Сборщик пишет только этот файл. Художественные правки в Studio сначала
сохранить отдельным файлом, затем перенести координаты/размеры/цвета в `world_art.py`. Не сохранять
единственную копию ручных правок поверх генерируемого результата: следующая сборка
их заменит. Сложные модели потребуют отдельного версионируемого источника и расширения
сборщика; текущий workflow предназначен только для блочной сцены.

Формат места: https://create.roblox.com/docs/projects/place-files

## Проверка

`python -m unittest discover -s tests -v`

Для проверки Luau скачать официальный CLI **0.744** из
https://github.com/luau-lang/luau/releases/tag/0.744, распаковать вне репозитория:

`python tools/validate.py --luau-dir <папка-с-luau-cli>`

Команда выполняет доменные тесты, strict-анализ чистой логики и компиляцию всех
скриптов. Временная копия обходит ограничение Unicode-путей Windows CLI; исходники
не меняются. Скачанные исполняемые файлы не добавляются в Git.

Автоматически проверяются воспроизводимость, внедрение актуальных скриптов,
наличие редактируемых островов/баз, Test namespace и отключённые платежи.
Это не замена запуску в Studio. Официальный Studio установлен 30 октября 2026;
импорт актуальной версии подтверждён, включая исправленный режим света и камеру.
Редакторский кадр: `assets/previews/studio-import.png`. Один клиент Studio
подтвердил загрузку, сбор и сохранение после перезапуска; телефон и несколько
клиентов остаются непроверенными. Подробности — STUDIO_IMPORT_REPORT.md.

Генерация собственных звуков: `python tools/generate_audio.py`.
WAV-файлы загружены под Masssha1337, владельцем Test experience; новые реальные ID
записаны в `BuildConfig.audio`. Копии под rakhmdam больше не подключены.
ContentProvider клиента Studio успешно загрузил все три файла. Качество
воспроизведения и работа на других устройствах ещё требуют проверки.

Полный список открытых проверок — [ACCEPTANCE.md](ACCEPTANCE.md).
Пользовательские игровые тесты отложены до завершения подключения ресурсов;
автоматическая проверка кода не является прохождением этих сценариев.

## Обновление уже существующего Test при зависании Publish As

1. Пересобрать место, затем выполнить `python tools/studio_import.py`.
2. Сохранить резервную копию старого места. Открыть именно облачный Test
   universe `10773715101`, place `82918888054660`, остановить Play.
3. File → Import Roblox Model → `places/SlimeSalvage-Import.rbxmx`.
4. В Command Bar Studio выполнить `require(workspace.SlimeSalvageImport.Installer)()`
   кнопкой Run. Это команда редактора Roblox, не игровой bootstrap.
5. Проверить `SLIME_IMPORT_OK`, предупреждения свойств, сцену и скрипты.
   Установщик отказывается работать в Play/другом universe/повторно с неразобранной
   резервной папкой. Он сохраняет заменённые объекты в ServerStorage и задаёт
   SlimeSalvageBuildHash; исходный XML определяет содержимое пакета.
6. После сверки и сохранения локального backup убрать служебные папки
   SlimeSalvageImportBackup/SlimeSalvageImportApplied из ServerStorage, выполнить
   обычный File → Publish, дождаться подтверждения версии в Output.

Установщик восстанавливает исходные координаты по CFrame Garden: нативный импорт
может автоматически сдвигать геометрию. После установки Garden должен быть (0, 1, 0).

В текущем Test Team Create отключён. Импорт и публикация версии 9 этим способом
подтверждены в установленном Studio. В пакете игровые Script/LocalScript выключены
до установки; не запускать Play до успешного завершения команды.
