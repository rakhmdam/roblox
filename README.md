# Roblox

Совместный проект игры для Roblox.

Игра будет разрабатываться авторами проекта в Roblox Studio. Код и файлы игры пока не добавлены.

## Совместная работа

- Основной репозиторий: https://github.com/rakhmdam/roblox
- Изменения сохраняем небольшими коммитами с понятными сообщениями.
- Для отдельных задач создаём ветки и pull request.
- Файлы мест Roblox (`.rbxl` или `.rbxlx`) храним в репозитории; перед изменением одного места договариваемся, кто его редактирует.
- Пароли, токены и другие секреты в репозиторий не добавляем.
