# Slime Salvage

Игра для Roblox о сборе и переработке хлама, развитии слаймов и путешествиях между островами.

**Основной репозиторий:** https://github.com/rakhmdam/roblox

ТЗ подготовлено. Начата техническая заготовка: редактируемый берег, серверный и клиентский bootstrap, воспроизводимая сборка места. Игровой цикл ещё не реализован; проверка Roblox Studio остаётся открытой. Старый прототип не перенесён.

## Первый запуск

Выполнить `python tools/build.py` (Python 3.10+), затем открыть
`places/SlimeSalvage-Test.rbxlx` в Roblox Studio. Подробности и ограничения:
[сборка](docs/BUILD.md). Тесты: `python -m unittest discover -s tests -v`.

## Совместная работа

- Изменения сохраняем небольшими коммитами с понятными сообщениями.
- Для отдельных задач создаём ветки и pull request.
- До реализации спорной механики фиксируем решение в дизайне.
- Файлы мест Roblox (`.rbxl` или `.rbxlx`) храним в репозитории; перед изменением одного места договариваемся, кто его редактирует.
- Пароли, токены и другие секреты в репозиторий не добавляем.
- Прохождение проверки структуры файлов не означает успешную проверку игры в Roblox Studio.
